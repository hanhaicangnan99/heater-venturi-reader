使用说明

      
    

    

      
流程

      
    
        
  • 顶部填日期、时间、记录人；首页选炉子（2# / 3# / 4# / 5#）→ 逐组录入 → 「下一组」→「完成本炉」回主界面。
    • 
        
  • 2#～5# 炉都录完后，回主界面点「绝压比计算」，填集合管压力生成方式2。
    • 
        
  • 每台炉卡片左下角有「清空」，只清空这一台炉的读数。
    • 
        
  • 每台炉 8 组：第 1～4 组 = A 炉膛，第 5～8 组 = B 炉膛。右上角可切换「整台 / A炉膛 / B炉膛」，只测半台时选 A 或 B。
    • 
        
  • 2号炉每组 2 块表（每行一组）；3/4/5号炉每组 12 块表（每行 6 块，两行一组）。
    • 
      

      
录入

      
    
        
  • 单炉页隐藏顶部栏：第一行只显示炉号和炉膛选择，第二行是加宽的返回主界面按钮；手机从页面中间向右划也能返回。
    • 
        
  • 单炉页主区域是相机实时画面；手机浏览器需要 HTTPS，没权限时点「打开相机」重试。
    • 
        
  • 进炉子页默认暂停，点中间大按钮「开始识别」后才接收识别读数；再点变成「暂停识别」。
    • 
        
  • 指定起点：点下面组内任意一块表，再点「开始识别」，就从这块开始；识别中点击某格会自动暂停。
    • 
        
  • 「上一组 / 下一组」在大按钮两侧；下一行是「跳过（送检）」和「剔除本块」。
    • 
        
  • 日常快捷更新（视觉识别备用）：首页「手动快捷输入」→ 导入页粘贴方式1并解析，或「不导入，直接手动」→ 选炉页始终显示全部 2/3/4/5 号炉，每台有「导出/算绝压比」勾选框和整台/A/B 范围，未勾选不应用、没输入行不写入；已导入的正常显示、未导入的虚线显示但也能点 → 单炉页一次改一组，顶部始终可选「整台/A炉膛/B炉膛」，点「下一组」；选炉页应用按钮下方有「导出文丘里压力」「返回主界面」「计算绝压比」；未导入的每组默认 1#、第一组 0.000，没改过的组跟随最近改过的那组；导入半台切整台时，空白组也跟随最近改过的组，被跟随的组会写回；位号和读数用大箭头调，位号旁有滑杆可快速拖动，位号到 1# 按↓回最大，读数到 0.000 按↓按位循环（千分位 0→9 等）；可开「反向输入」；最后「应用到本炉」。只更新最高表，其他表读数保留。
    • 
        
  • 点格子输入读数；回车跳到下一块，方向键按位置跳格，X 剔除当前读数，Esc 退出输入框。
    • 
        
  • 读数支持全角数字、带单位（0.170 MPa）、逗号小数点。
    • 
        
  • 识别模块识别到一个读数就调用一次 GaugeApp.pushReading(0.170)，会顺序填入当前识别位置；也可以点「识别填入」粘贴一批结果。
    • 
        
  • 「剔除」的读数不参与最高值，原始值仍保留在本机 JSON 中。
    • 
        
  • 表被送检：点「跳过（送检）」或格子右下「送」，该表标记为送检，不参与最高值/绝压比；点「送」可恢复。
    • 
        
  • 反向读取：点底部的「方向：正序/倒序」，整台炉按 组8→1、组内 12#→1# 识别。
    • 
        
  • 现场排表/换表：点「暂停识别」，换好表后点下面那一块表，再点「开始识别」，就从这块开始。
    • 
      

      
绝压比计算

      
    
        
  • 正常流程：先把所有炉子的文丘里读数录完，再去操作室看集合管压力。
    • 
        
  • 主界面点「绝压比计算」，会自动载入当前读数；也可以粘贴方式1文本（老记录/别人发来的）。
    • 
        
  • 粘贴的炉膛标题支持简写：4号炉A、4号炉 A、4号炉A炉膛、4号炉B侧 都能识别。
    • 
        
  • A、B 炉膛各填一个集合管压力（MPa）；绝压比 =（单炉膛最高 + 大气压）/（集合管压力 + 大气压），大气压取 0.1 MPa。
    • 
        
  • 两个炉膛取较大者作为「最大绝压比」，并标出最高读数所在的组，生成方式2。
    • 
      

      
导出

      
    
        
  • 导出文丘里压力（方式1）：每台炉一个标题（半台带 A/B炉膛），每组一行「最高值表号 最高值」。
    • 
        
  • 导出所有数据（顶栏）：Excel（.xlsx），所有数据一张表，每台炉一块、一组一行；组最高值加粗、剔除划线、送检写「送检」；每台炉附 A/B 集合管压力，最大绝压比注明第几组第几块。
    • 
        
  • 方式2：在「绝压比计算」页面生成，①～⑧ 圈号 + <表号>读数 + A/B集合管压力，最后一行「最大绝压比 ⑤ 0.84375」。
    • 
        
  • 只导出有读数的炉子；空组在方式1里显示为 - -。
    • 
      

      
安装到桌面

      
    
        
  • 手机 Chrome 打开线上地址 https://hanhaicangnan99.github.io/heater-venturi-reader/，点首页「安装到桌面」，或浏览器右上角 ⋮ → 安装应用 / 添加到主屏幕。
    • 
        
  • iPhone / iPad 用 Safari 打开，点底部分享按钮 → 添加到主屏幕。
    • 
        
  • 装好后桌面出现「读表」图标，全屏打开、没有地址栏；页面已缓存，断网也能打开已缓存部分。
    • 
      

      
手机打开

      
    
        
  • 手机只传一个文件：用 读表软件_手机版.html，CSS/JS 已内联；只传 index.html 会缺 js/、assets/，页面会空白或没样式。
    • 
        
  • 直接打开本地文件时，录入、导入导出、绝压比计算都能用；手机浏览器不允许 file:// 调用摄像头。
    • 
        
  • 要实时相机：页面必须在 https:// 开头的网址下；file:// 和 http://192.168… 都不允许调用摄像头。可把单文件放到 GitHub Pages / Netlify / 公司 HTTPS 服务器，或用 App 包壳；不要用微信/QQ 的文件预览打开。
    • 
        
  • 如果还显示旧界面：打开 https://hanhaicangnan99.github.io/heater-venturi-reader/?v=2.27.0 一次，或清除站点缓存；页脚会显示当前版本 v2.27.0。
    • 
      

      
数据

      
    
        
  • 每次修改自动保存在本机浏览器；换电脑/清缓存前请「导出所有数据」Excel 或「导出文丘里压力」文本备份。
    • 
        
  • 「导入 Excel」可把导出的 .xlsx 读回来，恢复读数、剔除、送检、集合管压力和日期时间；旧 JSON 备份也兼容。
    • 
        
  • 整个页面离线运行，不上传任何数据。
